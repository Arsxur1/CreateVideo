# 영화 제작 장인정신(Filmmaking Craft) — 고전 영화 규칙을 AI 생성 영상으로 번역

> 원서: Blain Brown, *The Basics of Filmmaking: Screenwriting, Producing, Directing,
> Cinematography, Audio & Editing* (Routledge, 2020) — AI 생성 파이프라인용으로 선별·번역.
> 영문 정식 스킬: `skills/creative/filmmaking-craft.md`. 이 문서는 **읽기용 한국어 판**이다
> (파이프라인이 로드하는 스킬이 아님).

## 개요

고전 영화 장인정신은 한 문제를 풀기 위해 만들어졌다: **편집실을 살아남는 영화를 만들 것.**
잘리지 않는 영화는 "편집 불가, 시청 불가, 배급 불가" 상태가 된다. 장인정신의 규칙 —
커버리지, 180도 라인, 30도 규칙, 연속성, 룸 톤, Murch 편집 위계 — 은 모두 *커터빌리티*
(편집 가능성)와 *공간 일관성*을 보장하려고 존재한다.

AI 생성 영상은 면제인 것처럼 보인다: 세트도, 크루도, 슬레이트도 없으니까. 그렇지 않다.
이 파이프라인이 생성하는 모든 멀티샷 내러티브는 여전히 **잘려야(cut)** 하고, 재생성을
가로질러 여전히 **공간적으로 일관**해야 한다. 실패 양상은 동일하다: 컷 사이에 끼워들어갈
앵글이 부족하고, 스크린 방향이 뒤집히고, 거의 같은 샷 사이에 점프 컷이 나고, 매 컷마다
죽은 정적이 흐르고, 약한 순간을 감출 커버리지 없는 마스터만 남는다.

이 스킬은 **번역 표**다: 물리 촬영 규칙 하나하나를 OpenMontage 아티팩트(`script`,
`scene_plan`, `asset_manifest`, `edit_decisions`)에 가해지는 구체적 제약으로 다시 쓴다.
지금 디렉팅 중인 스테이지의 해당 절만 읽으면 된다.

## 언제 쓰나

- 임의의 **멀티샷 내러티브 또는 시네마틱** 브리프.
- 파이프라인: `cinematic`, `hybrid`, `animation`(내러티브), `character-animation`.
- **커터빌리티**가 필요한 모든 장면 — 즉, 샷이 둘 이상인 거의 모든 장면.

공간 연속성 의무가 없는 1샷 키네틱 explainer, 데이터 시각화, 순수 모션그래픽은 건너뛴다
(이들은 `storytelling.md`와 모션그래픽스 플레이북이 다룬다).

## 스테이지별 읽기 지도

| 스테이지 | 읽을 절 | 잠그는 것 |
|---|---|---|
| `script` | §1 내러티브 구조·대사 | 인과, 갈등, 3막 비트, 보여주기 |
| `scene_plan` | §2 커버리지·연속성 **(핵심)** | 장면당 앵글, 스크린 방향 축, 커터빌리티 |

| 리뷰/자기평가 | §5 안티패턴 체크리스트 | "영화 망치기 10가지"를 AI-gen으로 매핑 |

## 이 스킬이 다루지 않는 것

**제외** — AI 생성에 무관한 물리 세트 물류:
프로듀싱, 크루 역할, 안전, 슬레이팅, 허가, 콜시트, 케이터링, 조명기 종류(Fresnel vs LED),
그립 하드웨어. AI 파이프라인의 디렉터는 픽셀과 오디오 스템을 통제하지, 세트를 통제하지 않는다.

**참조만(중복 금지):**
- 시네마토그래피 어휘(샷 종류, 렌즈 성격, 구도) → `skills/creative/video-gen-prompting.md`(정준 5요소 명세 + 원시어 약 200개).
- 마감(레터박스, 필름 페이스, 레이어드 오디오, 그레이드) → `skills/creative/cinematic.md`.
- Explainer 내러티브 아크 + Anti-Subjective Rule → `skills/creative/storytelling.md`.
- 컷 역학 기초 → `skills/creative/video-editing.md`.
- 더킹/LUFS/SFX 타이밍 → `skills/creative/sound-design.md`.

## §1 내러티브 구조·대사 (→ `script`)

### 플롯 vs 스토리 — 연대기가 아니라 인과

- **플롯** = 사건의 순서("여왕이 죽고, 왕이 죽었다").
- **스토리** = 인과로 이어진 사건("여왕이 죽고, 왕이 **슬픔 때문에** 죽었다").

"그리고 나서 … 그리고 나서 …"로 읽히는 비트 목록은 스토리가 아니라 플롯이다.
OpenMontage는 `storytelling.md`의 **but-therefore** 규칙을 계승한다: 비트는 **but** 또는
**therefore**로 연결하고, **and then**으로는 절대 연결하지 않는다. 할 수 없다면 그 비트엔
인과적 힘이 없는 것이다 — 자르거나 위험(stakes)을 올려라.

### 3막 구조(드라마틱, explainer 아님)

`script.structure` 마커에 이것들을 매핑하라. 이것은 **드라마틱** 아크이며,
`storytelling.md`의 explainer hook/tension/concept 아크와 구별된다; 둘을 섞지 마라.

| 비트 | 위치 | 기능 |
|---|---|---|
| Setup | 1막 | 세계, 주인공, 일상적 상태 |
| Plot Point 1(Inciting Incident) | 약 25–30% | 스토리를 출발시킴; 주인공에게 문제를 줌 |
| Midpoint | 약 50% | 새 장애물, 상향된 위험, 반전 |
| Plot Point 2 | 약 75% | 클라이맥스를 강요하는 위기 |
| Resolution | 3막 | 감정적으로 만족스러운 결말 — 편법이 아니라 벌어받은 것 |

### 갈등

모든 장면은 갈등이 필요하다. 없으면 죽은 무게다. 유형:
- 외부: 인물/인물, 인물/사회, 인물/자연, 인물/기계.
- 내부: 주인공 자신의 심리.

갈등 없는 장면은 (짧다면) 위험을 설정하거나, 잘라야 한다.

### 서브텍스트 — "on-the-nose" 회피

감정을 직접 진술하는 대사/내레이션("난 너무 슬퍼")은 on-the-nose다. 느낌이 아니라
**시각적 원인**을 진술하라. 이것은 `storytelling.md`의 **Anti-Subjective Rule**을 강화한다 —
주관적 표현은 픽셀을 제약하지 않는다. 느껴지는 것이 아니라 관찰 가능한 것을 써라.

### 보여주기, 말하지 말기(설명)

배경 정보는 필요악이지만 최소화하라. 설명 비트는 내레이션에 쏟지 말고 `scene_plan`의
**시각**에 매핑하라. 관객이 무언가를 전달받아야 한다면 정적 보이스오버 블록이 아니라
액션에 붙여라.

### 번역 표 — 각본 규칙 → `script` 아티팩트

| 규칙 | AI-gen 제약 |
|---|---|
| 플롯 vs 스토리 | 비트가 인과(`but`/`therefore`)로 연결, 연대기가 아님. "and then" 사슬은 기각. |
| 3막 | `script.structure`가 Setup / PP1 / Midpoint / PP2 / Resolution 마커와 대략적 위치를 갖는다. |
| 갈등 | 모든 장면에 갈등 유형(외부-*/내부) 태그; 갈등 없는 장면은 컷 대상으로 플래그. |
| 서브텍스트 | 내레이션은 관찰 가능한 원인을 서술, 맨 감정은 금지(Anti-Subjective Rule). |
| 보여주기 | 설명은 `scene_plan` 시각에 매핑; 내레이션에 정적 정보 덤프 없음. |

## §2 커버리지·연속성 (→ `scene_plan`) ← 핵심 절

> **커버리지 = 커터빌리티. 영화가 망가지는 1번 이유이자, AI-gen 장면이 망가지는 1번 이유다.**

샷 하나만 생성해 "커버"된 장면은 다시 잘라낼 수 없다. 그 샷에 약한 순간이 있으면 숨길
곳이 없다. 마스터 씬 메서드는 편집자가 항상 대안을 갖도록 정확히 이것을 위해 존재한다.
AI-gen에서 "커버리지 찍기"는 한 샷으로 버티기를 바라는 게 아니라, **장면당 여러 앵글을
선언하고 그것들을 생성하는 것**이다.

### 마스터 씬 메서드 + 커버리지 세트

각 내러티브 장면에 `scene_plan`은 선언한다:

1. **마스터** — 와이드, 장면 전체의 지리와 스크린 방향 축을 설정.
2. **커버리지** — 추가 앵글 ≥2: 오버숄더(OTS), 클로즈업(CU), 또는 컷어웨이/리액션.
3. **컷어웨이/인서트** — 리액션 또는 디테일 인서트 ≥1, 평평한 마스터를 깨기 위해.

마스터를 먼저 생성하라; 모든 커버리지 샷은 **마스터의 축을 참조**한다(같은 스크린 방향,
같은 지리). 이것이 가장 중요한 연속성 닻이다.

### 라인(180도 규칙)

두 피사체 사이(또는 피사체와 그들이 보는 대상 사이)를 가상의 축이 가로지른다. 라인의
한쪽에서 마스터를 한 번 찍으면, **그 장면의 다른 모든 샷도 같은 쪽에 머문다**. 선을
건너면 스크린 방향이 뒤집히고 — 관객의 공간 지도가 부서진다.

**정당하게 건너는 법**(꼭 건너야 할 때): 카메라가 건너가는 움직임을 보여주거나,
뉴트럴/인서트 샷으로 컷어웨이하거나, 선 위의 뉴트럴 앵글로 컷하라. 결코 조용히 뒤집지 마라.

### 30도 / 20% 규칙 + 투 렌즈 사이즈 규칙

함께 컷되는 두 샷은 컷이 점프 컷(결함)으로 읽히지 않도록 충분히 달라야 한다.

- **30도 규칙** — 인접 샷이 수평/수직으로 ≥30도 차이.
- **20% 규칙** — 같은 개념, 프레임 크기 변화 ≥20%로 표현.
- **투 렌즈 사이즈 규칙** — 신뢰할 수 있는 커터빌리티 기법: 커버리지 샷 사이에 **렌즈 크기**를
  바꾼다(예: 25mm 마스터 → 50mm 클로즈업). 렌즈 크기 두 단계 차이 = 항상 잘림; 한 단계는 안 됨.

망설이면 변화를 더 작게가 아니라 **더 크게**.

### 연속성의 종류

장면의 모든 샷(그리고 모든 재생성)을 가로질러 잠가라:

- **의상/외형** — 캐릭터 서술어가 모든 샷에서 동일.
- **스크린 방향** — screen-left를 향하던 캐릭터는 컷을 가로질러 screen-left를 유지.
- **소품** — 객체의 존재/부재가 일관.
- **시간** — 장면 내 time-of-day/조명 상태가 일관.

재생성은 연속성 오류의 AI 판이다: 매 리롤이 조용히 머리, 옷, 왼손잡이 여부, 시선 방향을
바꿀 수 있다. 장면별 **연속성 잠금(continuity lock)**에 이 서술어들을 고정하고, 그 장면의
모든 프롬프트에 가져가라.

### 에스터블리싱 샷

각 장면은 더 가까운 커버리지 이전에 **지리적 방향 지정** — 관객에게 위치를 알려주는 와이드 —
으로 시작한다. 장소 감각 없이 클로즈업으로 시작하는 장면은 정박하지 못하다.

### 번역 표 — 핵심 기능

| 물리 촬영 규칙 | AI-gen 제약 |
|---|---|
| "모든 장면에 커버리지를 촬영하라" | `scene_plan`이 **내러티브 장면당 앵글 ≥3** 선언: 마스터 + 커버리지 2(OTS / CU / 컷어웨이), 편집에 커터빌리티 부여. |
| "마스터 씬 메서드" | **마스터를 먼저** 생성(지리 + 축 설정); 모든 커버리지 샷이 그 축을 참조. |
| "항상 컷어웨이를 찍어라" | 모든 장면에 평평한 마스터를 깨기 위한 **컷어웨이/리액션 ≥1** 포함. |
| 라인 / 180도 | 한 장면의 모든 샷이 **스크린 방향 축**을 공유; 축 뒤집힘을 연속성 위반으로 플래그. 생성 프롬프트에서 스크린 방향을 수정. |
| 30도 / 20% 규칙 | 인접 생성 샷이 **≥30도 또는 프레임 크기 ≥20%** 차이, 아니면 점프 컷 위험 → 재생성 또는 리프레임. |
| 투 렌즈 사이즈 | **렌즈 크기 변경**으로 커버리지 컷(예: 25mm → 50mm); 두 단계 차이 = 항상 잘림. |
| 연속성(의상/방향/소품/시간) | 장면별 **연속성 잠금**(외형, 스크린 방향, time-of-day, 소품)을 모든 프롬프트에 적용; 재생성은 잠긴 서술어 보존. |
| 에스터블리싱 샷 | 각 장면이 더 가까운 커버리지 이전에 **지리적 방향 지정**(와이드)으로 시작. |

## §3 편집 결정 (→ `edit`)

### Walter Murch의 6법칙 — 우선순위순

두 후보 컷이 경쟁하면 우선순위로 가린다. 목록은 **순서**가 있다 — 감정이 지배한다.

1. **Emotion(감정)** — 이 컷이 이 순간의 감정에 기여하는가?
2. **Story(스토리)** — 의미 있는 방식으로 스토리를 전진시키는가?
3. **Rhythm(리듬)** — 리듬적으로 맞는 지점인가? 뷰어가 예상하기 직전에 와야 한다.
4. **Eye-trace(시선 추적)** — 관객의 시선이 어디에 있고, 컷이 그것을 어디로 보내는가?
5. **2D place on screen(2D 화면상 위치)** — 180도 축을 존중하는가?
6. **3D space(3D 공간)** — 물리적/공간적 관계를 보존하는가?

리듬은 완벽하지만 감정이 틀린 커터는 진다. 감정은 맞지만 라인을 깨는 커터는 — 하위
우선순위만 희생된다면 — 여전히 이길 수 있다.

### 6단계 편집 과정 → `edit_decisions`

| 패스 | 영화 용어 | OpenMontage 매핑 |
|---|---|---|
| 1 | Logging | 모든 생성 클립 리뷰; 사용 가능 테이크 태그, 실패한 재생성 폐기. |
| 2 | First assembly | 클립을 `script` 구조 순으로 배열(스케치). |
| 3 | Rough cut | 장면 순서 + 연속성 점검; 라인 위반, 점프 컷 수정. |
| 4 | First cut | 감독/프로듀서와 구조 잠금(사람 게이트). |
| 5 | Fine cut | 리듬 조임; 논쟁 컷마다 Murch 우선순위 적용. |
| 6 | Final cut | 사운드 디자인, 음악, 타이틀 추가; 결과물. |

### J 컷 / L 컷

- **J 컷** — 다음 샷의 오디오가 그 비디오 **이전에** 시작(오디오가 인도).
- **L 컷** — 현재 샷의 오디오가 다음 비디오로 컷한 **이후에도** 계속(오디오가 뒤따름).

둘 다 `skills/creative/video-editing.md`의 기초를 확장한다. 대사 인계를 부드럽게 하고
사운드 브릿지가 관객을 컷 너머로 데려가게 쓴다.

### 히든 컷, 매치 컷, 교차편집, 엘립시스

- **히든 컷 / 매치 컷** — 액션이나 프레임이 컷을 가로질러 일치, 연속으로 읽히게.
- **교차편집(cross-cutting)** — 두 장면을 번갈아 평행 긴장 빌드.
- **엘립시스** — 중간을 잘라 시간 압축.
- **지리 설정** — 시퀀스를 와이드로 열어 이후 타이트한 커터빌리티에 공간적 집을 준다.

### 결정 프레임워크

두 후보 컷이 경쟁할 때: Murch 목록을 위에서 아래로 걷고, 그들을 구별하는 첫 번째
우선순위가 승자. 논쟁 커터의 이유를 `edit_decisions`에 기록하여 재편집이 다시 논쟁하지 않게.

## §4 오디오 장인정신 — 번역 (→ `assets`)

물리 오디오 규칙은 세트 위 마이크에 관한 것이었다. AI-gen에서 "마이크"는 TTS 엔진과
앰비언트 생성기지만, 각 규칙의 **의도**는 살아남는다.

| 물리 규칙 | AI-gen 번역 |
|---|---|
| Rule #1 "마이크를 가까이" | TTS가 **곧** 대사 — 붐 거리 문제 없음. 하지만 **깨끗하고 고립된 내레이션 테이크**: 보이스를 별도 스템에, 음악/SFX 혼입 없게, 믹서가 주변을 더킹(`sound-design.md`). |
| Rule #2 "항상 녹음하라" | 모든 로케이션에 **항상 앰비언트 베드** 생성, 조용해 보이는 장면도. 영화의 정적은 결코 디지털 0이 아니다. |
| 룸 톤(로케이션당 ≥15초) | **로케이션당 일관된 앰비언트/룸 톤 트랙 하나**, 그 로케이션의 모든 컷에 재사용. 없으면 컷이 뻑뻑. |
| ADR(비싸고, 원본만큼 못 함) | TTS 테이크를 **첫 번째에** 제대로 잡아라. 편집 중 보이스 재생성은 비싼 ADR의 AI 판 — 배치 전에 provider + voice + 설정을 잠가라. |
| 스크래치 트랙 | 보이스를 확정하기 전에 **임시 TTS를 먼저** 생성해 타이밍을 잠그고, 그 다음 최종 보이스 패스. 임시 내레이션은 보이스 확정 전에 `scene_plan`/`edit` 타이밍을 실제 단어에 맞춘다. |

원칙: **영화의 절반은 오디오이며, 컷은 그 아래 앰비언트 베드에서 살거나 죽는다.**
훌륭한 화면에 뻑뻑하고 죽은 조용한 커터가 있는 장면은 아마추어처럼 느껴진다.

## §5 안티패턴 체크리스트 — "영화 망치기 10가지" (→ 리뷰/자기평가)

Brown의 "Top Ten"은 대부분 물리 세트 목록이다. AI-gen에 매핑되는 부분집합, 각각을 체크로 재표현:

| 망치기 | AI-gen 체크 |
|---|---|
| "커버리지 부족" | `scene_plan`이 **내러티브 장면당 앵글 ≥3**을 선언하는가? |
| "컷어웨이 없음" | 각 장면에 **컷어웨이/리액션 ≥1**이 있는가? |
| "나쁜 오디오" | **로케이션당 일관된 앰비언트 베드** + 고립된 내레이션 스템이 있는가? |
| "에스터블리싱 샷 없음" | 각 장면이 **지리적 방향 지정**으로 시작하는가? |
| "포스트에서 수정하자" | `scene_plan`/`assets`에서 고쳐야 할 것이 **`edit`으로 미뤄지고** 있는가? (커버리지와 연속성은 편집에서 고칠 수 없다 — 상류에 존재해야 한다.) |
| "미숙한 각본" | 각본이 단순 사건 나열이 아니라 **갈등 + 인과**를 갖는가? |

**가지치기(물리 전용, AI-gen에 N/A):** 초점 불량, 의도치 않은 카메라 흔들림, 노출 불량,
카메라 수평 불량, "현장에서 룸 톤 미녹음". 노출/초점은 다른 곳에서 다루는 image-gen 품질
게이트로 매핑; 흔들림과 수평은 생성 프레임에는 무관하다.

메타 안티패턴: **"포스트에서 수정하자."** AI 파이프라인에서는 "장면에 커버리지가 없다는 걸
편집 스테이지가 감출 거야"로 읽힌다. 안 된다. 커터빌리티는 `scene_plan`에서 만들어지지,
`edit`에서 구출되지 않는다.

## 자기평가 루브릭

각 행을 1–5점(5 = 완전 충족). 1–2는 critical 발견 — 체크포인트 전에 수정.

| 기준 | 1–5 | 5점의 모습 |
|---|---|---|
| 커버리지 | | 모든 내러티브 장면이 마스터 + 커버리지 ≥2 + 컷어웨이 ≥1, 모두 생성됨. |
| 축 일관성(180도) | | 장면 내 스크린 방향 뒤집힘 없음; 축이 마스터에서 명시적으로 적용됨. |
| 커터빌리티(30도/렌즈) | | 인접 샷이 ≥30도 또는 렌즈 크기 두 단위 차이; 점프 커터빌리티 위험 쌍 없음. |
| 에스터블리싱 샷 | | 모든 장면이 지리적 방향 지정으로 시작. |
| 연속성 잠금 | | 외형/스크린 방향/소품/시간이 고정되고 재생성을 가로질러 보존됨. |
| 오디오 베드 | | 로케이션당 일관된 앰비언트; 고립된 내레이션 스템; 뻑뻑한 컷 없음. |
| 각본 장인정신 | | 인과 비트(`but`/`therefore`), 모든 장면에 갈등, 주관적이지 않은 관찰적 내레이션. |
| 안티패턴 통과 | | §5 체크리스트 정상; 상류에 속할 것이 편집으로 미뤄진 것 없음. |

## 흔한 함정

- **장면당 한 앵글.** 고전적 사례. 잘라낼 곳 없는 "좋은" 샷 하나를 생성. 항상 커버리지를 선언하라.
- **조용한 스크린 방향 뒤집힘.** 재생성이 캐릭터 시선을 뒤집고 아무도 안 잡는다. 축 + 연속성 잠금을 모든 프롬프트에 가져가라.
- **거의 같은 인접 샷.** 거의 같은 앵글의 CU 둘 = 점프 컷. 30도/투 렌즈 사이즈를 강제.
- **앰비언트 베드 없음.** 매 컷이 디지털 정적에 착지. 로케이션당 룸 톤을 생성하고 재사용.
- **"포스트에서 수정."** 편집이 빠진 커버리지를 구출하길 바람. 안 됨 — 커버리지는 상류 결정.
- **on-the-nose 내레이션.** 감정의 시각적 원인을 보여주는 대신 감정을 진술(Anti-Subjective Rule 위반).
- **AI-gen이 연속성에서 면제라고 착각.** 정반대: 재생성은 *내장된* 연속성 위험이므로 잠금은 덜이 아니라 더 중요하다.
