# Yafho-Silicare — сценарий hero v2 «Окно перестройки»

**Этап 1 из 5: сценарий — утверждён.** Без голоса: титры + стрелки + музыка (решение заказчика). Название — **Yafho-Silicare**. Дальше: аниматик → 3D-сцены → кадры Kling → сборка и звук.

| Параметр | Решение |
|---|---|
| Длина | ≈ 78 с (9:16, 16:9, 4:5) + 3 нарезки по 15 с |
| Стиль | научно-документальный, спокойный, экспертный |
| Звук | без голоса: крупные титры + стрелки + эмбиент |
| Ранние этапы | абстрактно в 3D: без крови, раны и лиц |
| Главная мысль | Заживление идёт само. Но на самом долгом этапе — перестройке — можно повлиять. И именно там решается, каким станет рубец. |

**Сквозной приём — «шкала заживления».** Линия вверху кадра «День 0 → Дни → Недели → Месяцы» появляется в акте 2 и проходит через весь ролик. Она показывает, где мы сейчас в истории. В акте 4 отрезок «Месяцы» загорается оранжевым: это «окно», куда направлен продукт.
