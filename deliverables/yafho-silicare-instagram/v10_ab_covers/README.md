# v10 — A/B-обложки для 10 роликов

Для каждого ролика сделано 3 варианта обложки (1080×1920, текст лежит внутри безопасной зоны 4:5 сетки профиля, y 285–1635):

| Вариант | Механика | Когда побеждает |
|---|---|---|
| **A — вопрос** | белая строка + оранжевый вопрос | широкая аудитория, «хочу узнать ответ» |
| **B — факт** | цифра/факт, вторая строка на оранжевой плашке | B2B, врачи, сохранения |
| **C — эмоция** | белый текст с тенью, оранжевая черта | истории, репосты в личку |

Файлы: `{ролик}_{A|B|C}.jpg`, сводный лист — `ab_contact_sheet.jpg`.
Генератор: `source/covers_ab.py` (кадр берётся из ролика через ffmpeg, зона текста сильно размывается, чтобы надписи самого ролика не спорили с обложкой).

## Как тестировать
1. **Пробные Reels (Trial Reels)**, если функция доступна в аккаунте: публикуем один ролик с обложкой A как пробный (его видят только неподписчики), через 48–72 ч сравниваем с B/C по досмотрам и охвату.
2. Если пробных Reels нет: публикуем с A, через 72 ч в «Изменить → Обложка» ставим B, ещё через 72 ч — C. Сравниваем **прирост показов в сетке профиля и переходов из профиля** за каждые 72 ч (не общий охват — алгоритм ленты обложку почти не учитывает).
3. Метрика победы: CTR из профиля + доля досмотров первых 3 с. Победивший тип (A/B/C) переносим на следующие ролики серии.
4. Минимум 3 ролика на тип, прежде чем делать вывод — один ролик ничего не доказывает.

## Важно
- На обложке e2 «1 420 г.» — сценка, не реальный пациент (как и в самом ролике).
- «1 из 5 родов — кесарево» опирается на ВОЗ / Betran 2021 (21%).
- «2–3 слоя клеток» (m5) — та же неонатальная цифра, которая ещё ждёт сверки с первоисточником; до сверки лучше использовать A или C.
