# v20 — серия «ТЕСТ YAFHO»: эффект своими глазами

Ответ на отзыв «нужно показать ЭФФЕКТ, фон как на сайте, изюминку и широкий охват».

**Что изменилось по сравнению с прошлыми роликами**
- **Фон как на yafho.com:** серо-голубой градиент карточек товаров вместо тёмного «кино» и белого.
- **Эффект в кадре, а не в тексте.** Каждый ролик — эксперимент «слева обычный пластырь, справа силикон Yafho». Результат видно глазами: что осталось на коже, что — на пластыре.
- **Бытовые хуки для всех:** киви, новые туфли, детская коленка, «пусть подышит», красный след. Это знакомо каждому, а не только врачам.
- **Смысл в одной фразе** после эффекта («Обычный клей цепляется за каждый волосок…»), затем вывод-слоган и CTA с кодовым словом.
