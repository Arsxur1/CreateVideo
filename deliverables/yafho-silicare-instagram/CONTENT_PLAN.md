# Yafho Silicare — Instagram: стартовый набор (B2B, RU)

**Большая идея:** *«Снимать — не ранить.»*
Смена повязки для медсестры — процедура, для пациента — самая тяжёлая минута дня. Silicare делает эту минуту тише: силикон держит кожу, а не рану; пена и суперабсорбент держат экссудат.

**Аудитория:** дистрибьюторы медизделий, закупщики ЛПУ, старшие медсёстры, хирурги, специалисты по уходу за ранами.
**Цель:** понять продукт за 3 секунды → запросить образцы/спецификацию в директ.
