# Yafho · Instagram — с чего начать

0. **`READY_TO_POST/`** — папка на каждый день: подпись, первый комментарий, alt, обложки, сторис дня. Публикующему больше ничего не нужно.
1. **`MASTER/MASTER_CALENDAR.md`** — что и когда публиковать (51 публикация, 12.10.2026 → 27.04.2027), сетка — `calendar_preview.jpg`, таблица — `master_calendar.csv`.
2. **`MASTER/CAPTIONS.md`** — готовые подписи, хэштеги, первые комментарии и alt-тексты; `captions.csv` для планировщика.
3. **`v14_profile/`** — оформить профиль до первого поста: аватар, био, «Актуальное», закрепы.
4. **`v13_stories/`** — 18 сторис со стикерами под календарь.
5. **`v10_ab_covers/`** — по 3 обложки на 10 главных роликов и порядок A/B-теста.
6. **`MASTER/analytics_tracker.xlsx`** — еженедельная аналитика: внести цифры из статистики в жёлтые ячейки, остальное считается само.
7. **`v18_ads/`** — рекламные версии 4:5 и 1:1 + тексты и брифы кампаний (`ADS.md`).
8. **`v15_b2b/`** — ответы в директ на «КАТАЛОГ»/«ЛУПА», таблица заявок, одностраничник A4 для клиник.
